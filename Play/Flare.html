What is the local player?

Websim deleted the Codename: T4CTIC website, so I created the Local Player to allow everyone to continue playing the games they want to play (even if Websim gets banned).

When an update happens, the Local Player will update automatically through GitHub integration.

If any bugs are found, please report them to the Issues tab on the GitHub repo.

Some games may not work in the local player. If you find one like this, try downloading it and running the file
