# Codename-T4CTIC
Game Website using HTML Web ports, Web games, And soon possibly social media made by Other People, and then packaged into my website for In School Use. This github hosts the assets for Part 1 and 2 that the local Downloader and Player uses.

Website (Originally deleted, but now has been turned into a launcher for the new site): https://websim.com/@T4ctica1/tactic 

Website PT 2 (Discontinued): https://websim.com/@T4ctica1/2nd

Local Player: Go to the Releases Tab or go to https://drive.google.com/drive/folders/1gueTxTt1YjLbbwZ3YyQcZJkq9tbC5nse?usp=sharing

Thanks for using Codename T4ctic!

To play the games after downloading just open the HTML file by going to the Files app on the Task Bar or the Chrome/Edge Downloads Page, find the Game and double click the HTML file, this should open your game in either Edge or Chrome. 


Games from https://gn-math.github.io , https://Truffled.lol , and various other places

Cover images and BGs from https://steamgriddb.com

Sounds from Game Files, https://sounds.spriters-resource.com/ , and https://Youtube.com
